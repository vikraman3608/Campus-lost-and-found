# Campus Lost and Found

Campus Lost and Found is a web-based application designed to help students find lost belongings and report found items within the college campus. The website provides a simple and user-friendly interface where students can enter item details, descriptions, dates, and other relevant information.

## Features
- Report lost items.
- Report found items.
- Search for lost and found belongings.
- Enter item details and dates.
- User-friendly and colorful interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Objective
The main objective of this project is to connect students who have lost their belongings with students who have found them, making it easier to return items to their rightful owners.

## Future Enhancements
- Student login and registration.
- Image upload for items.
- Database integration.
- Notifications when matching items are found.
